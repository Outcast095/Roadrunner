**Проект:** Roadrunner - 3D симулятор внедорожника  
**Жанр:** Driving/Survival  
**Платформа:** Web (React + TypeScript + Babylon.js + Ammo.js)  
**Версия:** 0.0.0  

---

## 🎮 Концепция игры

### Основная идея
Игрок управляет внедорожником на квадратной карте пересеченной местности, собирая бочки с топливом для продолжения движения. Цель - выжить как можно дольше и собрать максимальное количество топлива.

### Игровые механики
- **Управление**: WASD для движения, мышь для камеры
- **Цель**: Сбор бочек с топливом для поддержания запаса горючего
- **Препятствия**: Деревья, камни, неровности местности
- **Физика**: Реалистичная физика автомобиля с подвеской
- **Карта**: Квадратная область 500x500 метров

### Условия игры
- **Поражение**: Когда заканчивается топливо
- **Прогресс**: Количество собранных бочек и время выживания
- **Рекорды**: Лучшее время и максимальное количество бочек
