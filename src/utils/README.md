# Utilities

Этот каталог содержит утилиты и вспомогательные функции.

## Структура

### `physics/`
- Ammo.js интеграция и физические утилиты
- Vehicle physics, terrain physics
- Collision detection и response
- Physics world management

### `graphics/`  
- Babylon.js утилиты и хелперы
- Mesh creation и manipulation
- Material и texture utilities
- Camera и lighting helpers
- Performance optimization utils

### Общие утилиты
- `math.ts` - Математические функции
- `async.ts` - Асинхронные утилиты
- `validation.ts` - Валидация данных
- `storage.ts` - Local storage helpers
- `performance.ts` - Performance monitoring

## Принципы

- Pure functions где возможно
- Strong typing
- Unit tests для критических функций
- Performance-первый подход
- Tree-shaking friendly exports
