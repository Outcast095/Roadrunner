# React Hooks

Этот каталог содержит пользовательские React hooks для игры.

## Структура

- `useGameState.ts` - Hook для работы с игровым состоянием
- `useVehicleControls.ts` - Hook для управления автомобилем
- `usePhysics.ts` - Hook для работы с физикой
- `useAssetLoader.ts` - Hook для загрузки ассетов
- `useAudio.ts` - Hook для работы со звуком
- `usePerformance.ts` - Hook для мониторинга производительности
- `useInput.ts` - Hook для обработки пользовательского ввода

## Принципы

- Custom hooks для переиспользования логики
- Strong typing с TypeScript
- Error boundaries integration
- Performance optimization (useMemo, useCallback)
- Cleanup в useEffect
- Testing-friendly design
