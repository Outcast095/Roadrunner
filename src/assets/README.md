# Game Assets

Этот каталог содержит все статические ресурсы игры.

## Структура

### `models/`
3D модели в различных форматах:
- `vehicles/` - Модели автомобилей (.glb, .gltf)
- `environment/` - Объекты окружения (деревья, камни)
- `collectibles/` - Собираемые объекты (бочки с топливом)
- `ui/` - 3D элементы интерфейса

### `textures/`
Текстуры и материалы:
- `terrain/` - Текстуры ландшафта
- `vehicles/` - Текстуры автомобилей
- `environment/` - Текстуры окружения
- `ui/` - Текстуры интерфейса
- `effects/` - Текстуры для эффектов

### `sounds/`
Аудио файлы:
- `engine/` - Звуки двигателя
- `environment/` - Звуки окружения
- `ui/` - Звуки интерфейса
- `music/` - Фоновая музыка
- `effects/` - Звуковые эффекты

## Принципы

- Оптимизированные форматы (WebP, AVIF для текстур)
- Compressed audio (OGG, MP3)
- LOD versions для моделей
- Consistent naming convention
- Asset bundling для production
