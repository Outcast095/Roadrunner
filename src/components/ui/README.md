# UI Components

Этот каталог содержит React компоненты пользовательского интерфейса.

## Структура

- `HUD/` - Игровой интерфейс (спидометр, топливо, счет)
- `Menus/` - Меню (главное, настройки, пауза)
- `Dialogs/` - Диалоговые окна и модалы
- `Controls/` - Элементы управления и формы
- `Layout/` - Компоненты компоновки

## Принципы

- Responsive design для разных экранов
- Accessibility (a11y) поддержка
- Theme support (dark/light)
- Анимации и переходы
- Keyboard navigation support
