# Game Components

Этот каталог содержит React компоненты для игровых 3D объектов.

## Структура

- `Vehicle/` - Компоненты автомобиля
- `Terrain/` - Компоненты ландшафта  
- `Objects/` - Игровые объекты (препятствия, collectibles)
- `Effects/` - Визуальные эффекты и частицы
- `Physics/` - Компоненты с физикой

## Принципы

- Каждый компонент должен быть самостоятельным
- Интеграция с Babylon.js через refs
- Типизация с использованием наших game types
- Performance-oriented: используем memo, lazy loading
