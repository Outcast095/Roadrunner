Документация к игре RoadRunner
1. 🎮 Общее описание

RoadRunner — это браузерная 3D-игра-симулятор управления внедорожником.
Игрок управляет джипом с помощью клавиш:

W / A / S / D — движение вперёд, назад и повороты;

SPACE — ручной тормоз.

На карте расположены препятствия (деревья, камни).
По мере игры появляются бочки с топливом, которые необходимо подбирать, чтобы продлить время езды.

Если топливо заканчивается — игра завершается.

Игра использует физический движок для моделирования гравитации, трения, упругости и столкновений объектов.


🛠 Технологический стек

Графика и физика

@babylonjs/core — отрисовка 3D сцены и объектов.

@babylonjs/loaders — загрузка моделей и ассетов.

@babylonjs/materials — материалы, шейдеры, эффекты.

ammo.js — физический движок (столкновения, трение, гравитация, упругость).

Фронтенд и логика

React — интерфейс и связывание UI со сценой.

React Router — маршрутизация (меню, экран игры, конец игры).

Zustand — глобальное состояние (топливо, статус игры, управление).

Инфраструктура

Vite — быстрая сборка.

TypeScript — типизация.

ESLint + Prettier — качество кода.

Playwright — e2e тестирование.

Husky + lint-staged — хуки и pre-commit проверки.
